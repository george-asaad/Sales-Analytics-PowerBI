# Sales Analytics Dashboard - Power BI

## Project Overview

This project focuses on cleaning, preprocessing, and analyzing sales data using Power BI. The objective was to transform raw sales records into meaningful business insights through interactive dashboards.

## Business Problem

Organizations often struggle to extract actionable insights from large volumes of sales data. This project addresses that challenge by cleaning inconsistent data, preparing it for analysis, and visualizing key performance indicators (KPIs) to support decision-making.

## Dataset

The dataset contains sales transaction records including:

- Order ID
- Customer Information
- Product Details
- Sales Revenue
- Quantity Sold
- Region
- Order Date

## Data Cleaning & Preprocessing

The following steps were performed:

- Removed duplicate records
- Handled missing values
- Corrected inconsistent data formats
- Standardized column names
- Created calculated columns and measures
- Performed data transformation using Power Query

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel

## Dashboards

### 1. Executive Sales Overview
Provides high-level KPIs including:
- Total Sales
- Total Orders
- Profit Analysis
- Sales Trends

### 2. Regional Performance Dashboard
Analyzes:
- Sales by Region
- Top Performing Areas
- Regional Revenue Distribution

### 3. Product Performance Dashboard
Tracks:
- Best-Selling Products
- Product Category Analysis
- Revenue Contribution by Product

## Key Insights

- Identified top-performing products and regions.
- Detected seasonal sales patterns.
- Highlighted areas requiring business attention.
- Enabled data-driven decision-making through interactive visualizations.
